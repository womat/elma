# Sicherheit

ELMA läuft im Heimnetz und ist über das Internet erreichbar. Hinweise auf Sicherheitslücken nehme ich deshalb ernst.

## Lücke melden

Bitte **kein öffentliches Issue** anlegen.
Stattdessen über GitHub privat melden: **Security → Report a vulnerability** ([direkt hier](https://github.com/womat/elma/security/advisories/new)).

Hilfreich sind:
- betroffene Version (steht in der App unten bzw. unter `/api/health`)
- Schritte zum Nachvollziehen
- was ein Angreifer damit erreichen kann

Ich melde mich in der Regel innerhalb einer Woche. ELMA ist ein Freizeitprojekt, eine feste Reaktionszeit kann ich nicht zusagen.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version.
